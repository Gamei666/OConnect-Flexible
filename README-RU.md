# OConnect Flexible

[English](README.md)

Самостоятельный Android-форк [OConnect v1.17.0](https://github.com/pengyue-polaron/oconnect-android/releases/tag/v1.17.0) с серверной раздельной маршрутизацией по доменам для ocserv.

- Получает dynamic split include/exclude через `X-CSTP-Post-Auth-XML`. Домен также охватывает его поддомены.
- Показывает доменные правила и IP-сети в **Деталях подключения → Маршруты**.
- В **Настройках → Язык приложения** доступны английский, русский и язык системы.

Требуется **Android 10 или новее**. В APK входят 32-битные ARMv7 и x86, а также ARM64 и x86-64. Подписанный APK доступен в разделе Releases этого репозитория. Если у вас уже есть отладочная сборка с другой подписью, потребуется новая установка. Сохраните нужные параметры профилей перед удалением старой сборки.

[Примеры настройки ocserv и ограничения DNS](docs/ocserv-RU.md)

## Сборка

Установите JDK 17, Android SDK Platform 37 и Build-Tools 36.0.0. Настройте `JAVA_HOME` и `ANDROID_HOME`. Сценарий использует Gradle Wrapper версии 9.5.1. Для сборки APK берутся проверенные нативные библиотеки из репозитория, поэтому NDK на этом этапе не требуется.

```powershell
.\build-android.ps1 -SdkPath C:\android
```

В Windows запустите этот сценарий из PowerShell. Он запускает тесты, lint, сборку и проверку подписи. Отладочный APK появится в `dist`. В Linux выполните `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`.

[Подпись релиза](docs/releasing-RU.md) · [Исходники и происхождение нативных библиотек](third-party/README-RU.md)
